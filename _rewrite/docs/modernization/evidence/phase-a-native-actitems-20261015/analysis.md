## Coherent network slice

The implementable continuation is the original three-stage action-item flow: actual `CS_ITEMUSE_REQ` for an owned type25 item starts an action; `CS_ACTITEMSUSE_REQ` consumes the actual skill's item and records acceptance; animation-generated `CS_FINISHSKILL_ACK` applies a bounded positive own-PC instant cure. ACT is a distinct producer, not an ordinary learned cast with different request bytes. It has no ordinary learned-skill HP/MP cost, reuse or charge operation. The supported effect must come from actual verified charts, not a fabricated learned rank or empty success.

The bounded effect profile is kind21, positive, nonserver, nonlinked, nonrepeated, own living partyless PC, no GOHOME mode, supported statistics/effects and empty excluded companion/recall/territory graphs. Every actual data row must be SA_ONCE/SDT_CURE/HP-or-MP, flat Calc0 with SVI_INCREASE. The trigger is not learned, so actual source finish rank and critical are0; the acceptance ACK still has source rank1. Richer definitions, learned triggers, negative attacks, other targets, special modes and general combat remain OPEN and must fail before item debit. No claim that a live published item currently satisfies this profile is made without Phase B data/client acceptance.
